# Shape It for How It Is Read

Speaker: Ignatius Fogwhistle, Copperkettle Systems (fictional)

Embed or reference? Ignatius argues from access patterns: put together what the application fetches together, duplicate small values that rarely change, and keep unbounded lists out of a single record. Worked examples from a fictional library catalogue show the before-and-after of each pattern, including the bucket and the extended reference patterns, and one migration that went badly.
