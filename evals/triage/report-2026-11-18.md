# Triage eval (2026-11-18)

Golden set: `corpus/sample/inbox-golden` (fictional), **10 messages**, every label verified. Escalation is disabled: each model runs alone on a one-rung ladder, with the same prompt and the same redaction as production. Prompt plus validate plus retry (no constrained decoding on Ollama Cloud).

**Labels seeded by:** hand. A set seeded from one model's output anchors on that model; what limits it is that a human verified every field and that this eval measures _other_ models against it.

## Corpus

- Messages per intent: speaker_reply 5, venue_reply 1, sponsor_enquiry 1, newsletter_or_noise 1, other 1, attendee_question 1.
- **Majority-class baseline for intent: 50% (always answering `speaker_reply`, 5 of 10).** Read every intent accuracy below against it.
- Majority baseline for sentiment_decision: 30% (`asks_question`).
- `needs_human` is true for 2 of 10; always answering "no human needed" scores 80% accuracy with 0% recall.
- **With 10 messages, one case is 10% of a score.** Differences of one or two cases are noise.
